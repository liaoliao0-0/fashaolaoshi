# fashaolaoshi

发烧老师数字分身 — 基于发烧老师（刘辰）投资哲学体系的 AI 角色扮演 Skill。

## 简介

模拟投资博主「发烧好了呢」的风格，用普通人听得懂的话回答投资问题。不荐股，不算命，不预测涨跌。

核心六条铁律：做好预期、拉好风控、不要allin、不要抄底、不上杠杆、动作不变形。

## 使用方式

### Claude Code（推荐）

```
# 通过斜杠命令触发
/fashaolaoshi 今天行情怎么样

# 自动触发词
发烧老师、仓位、风控、投姿
```

### 其他 AI 工具

本项目提供了工具无关的通用版 system prompt，适用于任何支持自定义提示词的工具：

| 工具 | 使用方式 |
|------|---------|
| ChatGPT | 粘贴到"自定义指令"或对话开头 |
| Claude Web | 粘贴到 Project 的 system prompt |
| Cursor | 粘贴到 `.cursorrules` |
| Windsurf | 粘贴到 `.windsurfrules` |
| Workbuddy / OpenCode | 粘贴到自定义 system prompt |

通用版文件：`fashaolaoshi-通用版-system-prompt.md`（约350行，所有内容合并为单文件）

## 行情查询

```bash
# macOS / Linux
python3 quote.py sh000300 hkHSI usNDX

# Windows
python quote.py sh000300 hkHSI usNDX
```

支持：A股(sh/sz)、港股(hk)、美股(us)、大宗商品(hf_)、国内期货(fut_)

## 设计原则

- **样本 > 规则**：规则是护栏，样本才是灵魂，冲突时以样本温度为准
- **约束 > 指令**：硬约束判定式，不是描述性建议
- **反模式 > 正向示例**：知道他不会说什么，比知道他会说什么更像他
- **少即是多**：入口轻量150行，知识按需加载
- **幽默是底色，不是模块**：每句话都带他的味道
- **像人 > 正确**：像朋友聊天，不像写研报

|------|-------|-----------|

| 2026.1 | 4 | 靴子duang/上半场/当代金融是预期的游戏/因地制宜 |
| 2026.2 | 2 | 上涨式回调/病树→春风 |

样本是 skill 风格还原的唯一权威来源，标注用"这句话为什么好"的口吻而非学术分析。

## 持续优化

每次直播后执行以下流程滚动提升 skill 质量：

1. 语音转文字放飞书
2. 提炼核心内容写回飞书
3. 从对话中提取 2-3 个 few-shot 样本追加到 `samples/真实对话.md`
4. 发现新的反模式追加到 SKILL.md 黑名单
