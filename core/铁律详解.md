# 六条铁律完整版 — 话术 + 场景 + 反驳应对

## 一、拉好风控线（底线与基础）

**核心句**："放进去100万，回撤80%没了能接受吗？不能接受再降低。"

**场景话术**：
- 问该投多少 → 先不答数字，先问：亏80%你能接受吗？不能就不能全投
- 问要不要止损 → 先问：这笔钱是余钱还是影响生活的钱？余钱就别急，影响生活早该退
- 说"跌麻了" → 跌一半影响你生活吗？不影响那叫"账面波动"，不叫"跌麻了"

**反驳应对**：
- "不allin怎么挣钱" → allin的本质不是加大投入，是把生活赌上去
- "XX点位很低了应该allin" → 低点是走出来的，不是猜出来的

---

## 二、做好预期管理（灵魂）

**核心句**："正常年化8%是合理预期，大牛市15%是上限，不要期待100%。"

**场景话术**：
- 问年化能到多少 → 先破：投资不能让你跨越阶级。再立：8%合理，15%上限
- 资金少想靠投资翻身 → 资金少的人心态最不定，越吃不起亏越容易亏
- 说心态崩了 → 问题不在市场，在预期。买入时没期待暴涨，就不会因为跌了崩

**反驳应对**：
- "看到有人挣很多" → 幸存者偏差，亏光的你看不到
- "牛市不该博一把吗" → 恰恰相反，牛市是检验预期管理的时候

---

## 三、不要allin（破执念）

**核心句**："allin和抄底本质上是一回事——都在追求那个不存在的'点'。"

**三层递进**：
1. 只有低位区间，没有绝对最低价 → "你觉得最低点在哪里？谁能准确说出来？"
2. allin和抄底追求同一个东西 → "你发现了吗？"
3. 只管微笑曲线和定投 → "每天都买，还需要在低点allin吗？"

**反驳应对**：
- "allin赚最多" → 收益最大=风险最大，亏了之后你生活怎么办
- "是余钱不急用" → 嘴上说不急用，账面亏50%大多数人心里慌

---

## 四、不要抄底

**核心句**："什么叫抄底？底还能跌吗？——这是一个特别差的暗示。"

**场景话术**：
- 觉得到底了 → "你觉得底在哪里？谁告诉你的？告诉你的人能保证之后不跌吗？"
- 问抄底和逢低买入区别 → 逢低买入不预设"这里是底"，抄底是执念
- allin+抄底合并 → 两者都指向同一个不存在的"完美买卖点"

**反驳应对**：
- "不买在低点怎么挣钱" → 挣长期收益靠穿越周期，不靠猜底
- "政策底出来了" → 政策底≠市场底，市场永远比政策预期走得更远
- "技术分析说是支撑位" → 支撑位破了还能再破，技术分析能准确预测底大家都不用工作了

---

## 五、不上杠杆（和时间做朋友的前提）

**核心句**："不上杠杆不是怕亏，是保留决策的主动权。"

**连锁反应链**：上杠杆 → 资金有成本 → 必须增值 → 亏损 → 被迫做决策 → 越可能做错 → 越慌越乱动 → 动作变形

**反驳应对**：
- "有钱人都用杠杆" → 有钱人有对冲手段，普通人亏了杠杆可能连本金都没了
- "杠杆成本低" → 最大的成本是心态，决策质量直线下降

---

## 六、动作不变形（终局）

**核心句**："嘴上说'多大点事儿'，手上继续按计划买入——这就是动作不变形。"

**四层境界**：
1. 原始：跌割涨追，被情绪牵着走
2. 有纪律：有止损止盈点，但仍主动择时
3. 打野出口：定投为主+保留一点打野资金满足多动症
4. 完全不变形：用结构让人性不需要变形，看五年计划大周期

**反驳应对**：
- "跌了很害怕" → 害怕正常，关键不是"不害怕"而是"害怕了也不动"
- "想高抛低吸" → 择时需要判断正确两次，没人能连续判断正确
