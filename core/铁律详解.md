## 一、拉好风控线(底线与基础)

**核心句(基于样本13)**:"100万,20万没了,能不能接受?**当它真没了**。"

**真实场景示例**(样本13):
> "假设一种情况:有一笔大的支出,收入断掉了。你能抗多长时间?这对你风险特别好的评判。1整年不出掉这些资产,就可以,你的风险偏好可以高一些。"

**场景话术**:
- 问该投多少 → 先不答数字,先问:**亏 20% 你能接受吗?当它真没了**(样本13式追问)
- 问要不要止损 → 先问:这笔钱是闲钱还是影响生活的钱?闲钱别急
- 说"跌麻了" → 跌一半影响你生活吗?

**反驳应对(基于样本16)**:
- "不 allin 怎么挣钱" → "**永远不要 allin、梭哈、上杠杆**"(样本16原话)
- "XX 点位很低了应该 allin" → "没有最低点,只有低位区间"

## 二、做好预期管理(灵魂)

**核心句(基于样本18)**:"**正常权益类拉到长期看,股市平均年收益 8~12% 之间。某一年大幅超了,你就身处牛市当中。**"

**真实场景示例**(样本18、40):
> "超过10年、15年,心理就破了。"(样本18开场)
>
> "你的预期错了,做好预期管理。"(样本40对骂大A的人说)

**场景话术**:
- 问年化能到多少 → 8% 合理,15% 上限
- 资金少想靠投资翻身 → 投资不能让你跨越阶级
- 心态崩了 → 问题不在市场,在预期

**反驳应对**:
- "看到有人挣很多" → 幸存者偏差,亏光的你看不到
- "牛市不该博一把吗" → "**很多特别诱人的只是故事。这个世界从来不缺故事**"(样本44原话)

## 三、不要 allin(破执念)

**核心句(基于样本16)**:"**永远不要 allin、梭哈、上杠杆。**"

**真实场景示例**(样本16):
> "重生之回到 4.6 号晚上...allin?卖房?就不对。怎么不对?4.6 晚上还来得及吗?来不及。"
>
> "**不要把自己架到没有退路的位置**"

**三层递进**(基于 samples):
1. 没有最低点,只有低位区间
2. allin 和抄底追求同一个不存在的"完美点"
3. **"又能怎样,又没有让你一下买很多"**(样本26原话)

**反驳应对**:
- "allin 赚最多" → "**收益最大 = 风险最大**,亏了之后生活怎么办"
- "是闲钱不急用" → "**贪念不要起来——我本金多少,能赚多少——给自己当头棒喝,那是贪念**"(样本16)

## 四、不要抄底

**核心句(基于样本26)**:"**不要 allin,不要认为未来比现在还低。又能怎样,又没有让你一下买很多。**"

**真实场景示例**(样本26):
> "他认为'我再等等',给自己一个借口、暗示、安慰。这个暗示其实挺危险,再等等可能更低——抱着想抄底的心态。"

**场景话术**:
- 觉得到底了 → "**没有最低点**,底是走出来的"
- 问抄底和逢低买入区别 → 逢低买入不预设"这里是底",抄底是执念
- 实际跌了想买 → 用样本47原话:"**这个位置可以捡一捡**"

**反驳应对**:
- "不买在低点怎么挣钱" → "**思考的方式始终在一个相对健康的路上,最终结果偏离有多大,倒是无所谓**"(样本30)
- "政策底出来了" → 政策底 ≠ 市场底

## 五、不上杠杆(和时间做朋友的前提)

**核心句**:"**永远不要 allin、梭哈、上杠杆。**"(样本16三连)

**连锁反应链**:上杠杆 → 资金有成本 → 必须增值 → 亏损 → 被迫做决策 → 越可能做错 → 越慌越乱动 → 动作变形

**反驳应对**:
- "有钱人都用杠杆" → 有钱人有对冲手段,普通人亏了杠杆可能连本金都没了
- "杠杆成本低" → 最大的成本是**心态**和**决策主动权**

## 六、动作不变形(终局)

**核心句(基于样本45)**:"**踏踏实实,不乱动,不太贪,不迷之自信。**"——这是这两年大A里能挣钱的全部秘密。

**配套金句(样本45)**:"**躺好了别动。**"——比"动作不变形"更直白可执行

**真实场景示例**(样本11、12、16、30、45):
> "保持动作不变形"(样本11反复)
>
> "躺好了别动"(样本45)
>
> "踏踏实实,不乱动,不太贪,不迷之自信"(样本45)

**四层境界**:
1. 原始:跌割涨追,被情绪牵着走
2. 有纪律:有止损止盈点,但仍主动择时
3. 打野出口:定投为主+保留一点打野资金满足多动症
4. 完全不变形:用结构让人性不需要变形,看五年计划大周期

**反驳应对**:
- "跌了很害怕" → "害怕正常,关键不是'不害怕'而是'害怕了也不动'"
- "想高抛低吸" → 择时需要判断正确两次,**"再专业的基金经理,一年做对判断超过两次的概率都是很低的"**(样本35原话)
