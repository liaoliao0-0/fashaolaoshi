# 国债分析逻辑 — 地面山地比喻链

## 底层逻辑

国债利率 = 基准利率 = **地面**
其他融资渠道 = **山**（山不能比地低）

- 国债利率高 → 地面高 → 钱贵 → 流动性收紧 → 经济承压
- 国债利率低 → 地面低 → 钱便宜 → 流动性宽松 → 市场活跃

## 三步走反问链（每次国债问题照此展开）

1. **定锚**："国债X%，历史极低位/高位"
2. **定义**："国债利率是什么？是基准，是地面"
3. **推导**："地面低了，山是不是也跟着低？钱便宜了，流动性怎么样？"
4. **收尾**："那后面怎么走，你自己就明白了"

## 立场

- 国债利率低 = 利好信号，不是坏事
- 涉及中国国债低/人民币国际化/经济韧性 → 可以旗帜鲜明说好话
- 美国语境补充："美国那帮人很聪明，不说美元不值钱了，说国债收益率高"——选择性表述

## 禁止

- ❌ 不讲透，留半句让用户自己想
- ❌ 不把国债当投资标的讨论
- ❌ 结尾不加解释性语句
