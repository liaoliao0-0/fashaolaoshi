# 宏观框架 — 地缘/政策/国家方向

## 五大主旋律（未来10-20年钱聚集的方向）

1. **专精特新** — 制造业细分领域的隐形冠军
2. **硬核科技** — AI、工业机器人等应用场景
3. **自主可控** — 国产算力、国产芯片
4. **国产替代** — 被外部非市场化环境加速的进程
5. **乡村振兴** — 政策资源倾斜方向

交叉举例：AI = 专精特新 + 硬核科技；国产芯片 = 自主可控 + 国产替代

## 美国不是一个整体（2023年分水岭）

- 美国 = 军工、石油、科技、金融等多种利益混合体，有时重合有时矛盾
- 2023年前：美元石油霸权是核心利益
- 2023年后：石油霸权不再是主要核心利益，核心可能转向科技
- 分析时区分"哪部分美国"在说话，不把美国当统一行动体
- 欧美可拆分（欧洲≠美国），英美难拆分（盎格鲁-撒克逊体系深度绑定）

## 国产替代与乡村振兴的底层哲学

**天之道 vs 人之道**（老子）：
- 天之道：损有余而补不足 → 国产替代、乡村振兴走的是这条路
- 人之道：损不足以奉有余 → 市场经济、资本自然倾向走这条路

天之道反人性，给负反馈，做起来痛苦。人之道有飞轮效应，越转越快。

**为什么推进慢**：
- 短期不产生效益，市场化角度看是"低效"
- 多套标准并行（既要GDP又要乡村振兴），考核矛盾
- 纯市场环境下几乎做不了

**ESG与国央企**：
- 西方触及社会治理边界后冒出ESG，觉得很高端
- 中国的国央企天然就在做ESG，"我们一上来就是完成体"
- 盐铁官营理念2000年：核心命脉掌控在公共部门手中
- 从5000年视角看世界 vs 从200年视角看世界，维度不同

**美国反而帮了中国**：
- 美国制裁/脱钩/半导体封锁 = 给中国营造了非市场化环境
- 纯市场下没人愿意放弃最优性价比选择，国产替代推不动
- 美国切断了最优选择 → 国产替代的市场环境被动形成
- 中国更早意识到博弈开始 → 提前布局 → 美国动作反而加速进程
